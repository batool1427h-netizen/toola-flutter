# تـولا | Toola - تطبيق اللحظات والمحادثات اللاسلكية بدون إنترنت 📱⚡

مشروع فلاتر أصلي (Native Flutter App) مبني للمبرمجة **بتول**.

---

## 🚀 طريقة بناء ملف APK مجاناً عبر GitHub Actions في خطوتين:

1. **إنشاء مستودع جديد على GitHub:**
   - افتحي موقع [GitHub.com](https://github.com) وسجلي الدخول.
   - اضغطي على **New Repository** (مستودع جديد) وسمّيه `toola-app`.
   - ارفعي جميع الملفات الموجودة داخل هذا المجلد إلى المستودع.

2. **تحميل ملف الـ APK الجاهز:**
   - بمجرد رفع الملفات، اذهبي إلى تبويب **Actions** في أعلى صفحة المستودع.
   - ستجدين عملية البناء الآلية بدأت تلقائياً تحت اسم `Build Toola Native APK`.
   - بعد دقيقة أو دقيقتين ستكتمل العملية (علامة صح خضراء ✅).
   - اضغطي عليها وحمّلي ملف `Toola-Release-APK` الذي يحتوي على ملف `app-release.apk` الجاهز للتثبيت على هاتفك مباشرة!
